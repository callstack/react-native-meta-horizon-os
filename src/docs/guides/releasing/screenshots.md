# Screenshots

High-quality screenshots are essential for your store listing. Capturing them in VR requires specific techniques.

## Meta Quest Developer Hub

Use [Meta Quest Developer Hub](https://developers.meta.com/horizon/documentation/native/android/ts-mqdh/) for consistent screenshots:

1. **Connect device**: Connect Quest via USB and find your device under "Device Manager"

![Connect your device via USB](/screenshots/connect-device.webp)

2. **Cast Device**: Enable casting to see live viewport

![Live viewport preview window](/screenshots/live-viewport.webp)

3. **Capture**: Use screenshot tools in the cast view

## 2D App View

For best results, use the 2D app view:

![Select 2D app view](/screenshots/2d-app-view.webp)

- **Isolated interface**: Captures only your app UI
- **Clean background**: Can be embedded in promotional backgrounds later
- **Consistent framing**: Easier to align and compose

## Best Practices

### Composition

- **Fill viewport**: Ensure app fills most of the captured image
- **Clean background**: Enable Immersive Home to remove clutter
- **Well-lit**: Keep environment well-lit for better quality

### Alignment

- **Consistent positioning**: Keep app in the same position across screenshots
- **Proper framing**: Avoid cutting off important UI elements
- **Preview first**: Check composition before final capture

### Styling

- **Promotional backgrounds**: Add backgrounds in post-production
- **Consistent style**: Match style across all screenshots
- **Clear text**: Ensure UI text is readable
