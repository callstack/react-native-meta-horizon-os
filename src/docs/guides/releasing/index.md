# Releasing & Publishing

This guide covers building, submitting, and publishing your React Native app to the Meta Horizon Store.

## Overview

The publishing process involves:

1. **Building** - Create a production-ready APK
2. **Submitting** - Upload through Meta Developer Hub
3. **Screenshots** - Create store assets
4. **Monetization** - Configure pricing and purchases
5. **CI/CD** - Automate your workflow

## Prerequisites

Before publishing, ensure you have:

- [Meta Developer Account](https://developers.meta.com/horizon/sign-up/)
- [Meta Quest Developer Hub](https://developers.meta.com/horizon/documentation/unity/ts-mqdh/) installed
- Production build configured with `expo-horizon-core`
